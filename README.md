# Randora Random

Открытая реализация равновероятного случайного выбора без повторений.

## Как работает выбор

1. Алгоритм получает список с уникальными идентификаторами участников.
2. Криптографически стойкий генератор случайных чисел выбирает заданное количество элементов.
3. Один участник не может быть выбран дважды.
4. При одинаковых входных условиях каждый участник имеет равную вероятность выбора.

Алгоритм использует `secrets.SystemRandom` из стандартной библиотеки Python.

## Запуск

```bash
python3 randomizer.py example_participants.json 2
```

Результат выводится в JSON.

## Формат входных данных

```json
[
  {
    "participant_id": "participant-1"
  },
  {
    "participant_id": "participant-2"
  }
]
```
